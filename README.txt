# Site de Produtos de Afiliado

## Adicionar produtos

Abra o arquivo `products.js`.

Cada produto possui somente 3 informações:

- `title` = título do produto
- `image` = caminho da imagem
- `link` = seu link de afiliado

Exemplo:

{
  title: "Fone Bluetooth",
  image: "assets/fone.jpg",
  link: "https://seu-link-de-afiliado.com"
}

Coloque a imagem em `assets/` e use o nome dela em `image`.

A ordem dos produtos no arquivo é a ordem em que eles aparecem na página.

## Publicar

Você pode publicar esses arquivos em qualquer hospedagem de site estático. Depois, coloque o endereço da página no campo de link da bio do Instagram.

## Importante

Troque o link de exemplo em `products.js` pelo seu link de afiliado antes de publicar.
